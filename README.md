# League of Legends – Champion Analysis & Battle Simulation

## About the Project

This project explores League of Legends champions through data analysis, object-oriented programming, and statistical visualization.

The main idea is to analyze champion attributes, compare their strengths and weaknesses, and build a battle simulation based on their in-game statistics.

The project combines data analysis with Python programming to explore how different champion characteristics can influence battle outcomes.

## Technologies & Libraries

- **Python** – Core programming language
- **Pandas** – Data manipulation and statistical analysis
- **NumPy** – Numerical operations and calculations
- **Matplotlib** – Data visualization and statistical charts
- **Object-Oriented Programming (OOP)** – Modeling champions and their attributes

## Project Goals

- Collect and organize League of Legends champion data.
- Explore champion attributes such as HP, attack damage, defense, magic, and movement speed.
- Compare champions based on their statistics.
- Create champion classes using OOP.
- Develop a battle simulation based on champion attributes.
- Analyze battle statistics and explore different matchups.
- Visualize champion performance and statistical comparisons.

## Planned Features

- Champion statistics analysis
- Champion comparison
- Attack and defense analysis
- HP and damage comparisons
- Statistical visualizations
- OOP-based champion models
- Battle simulation
- Battle results analysis

## Dataset

The project uses champion data containing attributes such as:

| Attribute | Description |
|---|---|
| HP | Health points |
| Attack Damage | Physical attack damage |
| Attack | Attack rating |
| Defense | Defense rating |
| Magic | Magic rating |
| Difficulty | Champion difficulty |
| Movement Speed | Movement speed |
| Tags | Champion classes and roles |
